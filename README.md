# Project Portfolio

# Featured Projects

## 1. Auto Test Tool (Firmware Testing Automation)
A Python-based automated testing tool developed during my firmware internship at **Coretronic Corporation**.

**Key Features**
- Automated device validation and testing workflow
- Script-based batch testing using YAML
- Communication with devices via **UART / RS232 / Telnet**
- Automated image capture and log collection
- GUI interface for building and executing test sequences

**Technologies**
Python · UART · RS232 · Telnet · YAML · Automation Testing
